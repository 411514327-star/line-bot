# 專案計畫書：群組相簿 LINE Bot

> **文件說明**：這份計畫書是 2026-10-12 依專案最初構想與實際完成的內容重新整理的版本。最初構想（名稱為「週週相簿」）後來在實作時做了調整，差異列在最後一節。

## 一、專案簡介

**名稱**：群組相簿 Bot（靈感來自 Retro — Photos with Friends）

**一句話說明**：把 LINE 群組變成朋友的共享相簿。大家傳照片，Bot 自動收進相簿，輸入「回顧」就能用輪播看最近的照片。

**動機**：LINE 群組的照片很容易被洗版，過幾天就找不到。Retro 證明了「小圈子、低壓力、定期回顧」的分享方式有人需要，這個專案把概念搬到最常用的 LINE 群組。

## 二、目標使用者與情境

- 朋友、家人、室友或社團的 LINE 群組。
- 情境：週末出遊後群組丟了一堆照片，想回頭看看這幾天發生了什麼。

## 三、功能範圍

| 編號 | 功能 | 說明 |
|---|---|---|
| F1 | 收照片 | 群組有人傳圖片，Bot 下載儲存並回覆確認 |
| F2 | 回顧 | 輸入「回顧」以 Flex Message 輪播顯示最近 7 天的照片；「回顧 N」可指定天數 |
| F3 | 使用說明 | 輸入「說明」顯示使用方式 |
| F4 | 輸入檢查（改善版加入） | 天數格式錯誤、不認識的文字、不支援的訊息類型都有引導；私聊提示改在群組使用 |
| F5 | 錯誤處理（改善版加入） | 照片下載失敗時提示重傳；防止同一則訊息重複寫入 |

刻意不做（列為未來擴充）：自動排程推播、月回顧拼貼圖、提醒未分享的人、Rich Menu。

## 四、LINE 功能運用

- Messaging API Webhook（接收訊息與圖片）
- 群組事件（以群組 ID 區分各群組的相簿）
- Flex Message Carousel（輪播呈現照片）
- Reply Message（即時回覆）

## 五、技術架構（實際採用）

- Python、FastAPI、uvicorn
- line-bot-sdk、python-dotenv
- SQLite（`album.db`）儲存照片紀錄；照片檔存在 `static/photos/`，由伺服器以 `/static` 提供
- cloudflared quick tunnel 提供公開 https 網址（`BASE_URL`）

流程：使用者在群組傳圖片 → LINE 呼叫 `/callback` → Bot 用 message ID 下載圖片並存檔、寫入資料庫 → 回覆確認 → 使用者輸入「回顧」→ Bot 查詢近期照片並組成 Flex Carousel 回傳。

## 六、版本規劃與實際進行

| 版本 | 內容 | 使用工具 |
|---|---|---|
| 基準版（第一版） | 收照片、回顧最近 7 天、說明；不認識的文字原樣回覆 | Antigravity |
| 第二版 | 輸入檢查（回顧 N、無法辨識的指令、不支援的訊息類型、私聊限制） | Antigravity |
| 第三輪 | 照片下載錯誤處理、防止重複寫入、`BASE_URL` 警告、移除提示文字的反引號 | OpenCode |

## 七、風險與對策

| 風險 | 對策 |
|---|---|
| 圖片網址不是 https，Flex 無法顯示 | 使用 tunnel 提供的 https 網址，啟動時檢查 `BASE_URL` |
| LINE 圖片內容有時效 | 收到圖片當下立刻下載儲存 |
| quick tunnel 網址會變 | 每次重開後更新 `.env` 與 Webhook 網址 |
| AI 產生的程式有錯 | 一次只做一個改動，每次改完都在 LINE 上實測 |
| 金鑰外洩 | 金鑰放 `.env` 並加入 `.gitignore`，倉庫只放 `.env.example` |
