# LINE Bot 測試紀錄表 (Test Log)

本文件紀錄「LINE 群組相簿 Bot」之測試歷程與改善前後對照。所有實際測試結果皆由開發者於實機（LINE App 手機端與測試群組）親自測試後記錄。

---

## 一、測試環境資訊

- **作業系統**：Windows
- **後端環境**：Python 3.14 + FastAPI + Uvicorn
- **LINE SDK**：line-bot-sdk v3.10+ (Messaging API & Blob API)
- **公開穿透閘道**：Cloudflare Tunnel (`https://amber-spend-presently-geek.trycloudflare.com`)
- **測試帳號與群組**：LINE Bot 測試群組（3人）及個人一對一聊天室

## 四、改善前後成果對照總結

| 評估面向 | 改善前（Commit 1 基準版） | 改善後（Commit 2 改善版） | 改善效益 |
| :--- | :--- | :--- | :--- |
| **指令彈性** | 僅固定查詢 7 天（輸入 `回顧 3` 僅 Echo） | 支援動態天數（`回顧 3`、`回顧 14`），未帶參數預設 7 天 | 大幅提升使用者彈性，滿足不同週期回顧需求 |
| **指令容錯與防呆** | 輸入非數字（如 `回顧 abc`）無提示，僅當一般訊息 | 嚴格型別校驗，提示需輸入有效數字並提供清楚範例 | 避免無效查詢，主動修復使用者操作疑惑 |
| **不支援訊息引導** | 傳貼圖、語音、影片皆已讀不回，容易誤認當機 | 主動攔截並告知僅支援照片，引導輸入「說明」查閱指南 | 消除「已讀不回」的負面體驗，形成閉環互動 |
| **未知文字處理** | 單純 Echo 重複使用者傳送的文字 | 明確告知無法辨識，並引導使用者查詢功能說明 | 具備專業聊天機器人之意圖辨識反饋體驗 |
| **聊天場景防護** | 私聊傳照片與回顧均照常處理，易造成群組混淆 | 明確區分群組與一對一私聊，私聊時溫和提示加入群組 | 確保相簿資料歸屬正確，保護群組隱私與使用邊界 |
